Cloud Infrastructure Components

1. Compute Resources
Purpose: Supplies the CPU and RAM needed to run applications, programs, and workloads.
Importance in cloud computing: Computing power is one of the main resources provided by cloud services because it handles code execution, application hosting, and data processing, such as AWS EC2, Azure Virtual Machines, and Google Compute Engine.
In this environment: The KillerCoda VM serves as the compute resource. Its CPU cores and RAM, identified in Checkpoint 2, determine how much processing work it can handle.

2. Storage Resources
Purpose: Stores files, databases, logs, and other data so they remain available even when the compute instance is stopped or removed.
Importance in cloud computing: Cloud storage needs to be reliable, scalable, and capable of preserving data separately from the computing resources.
In this environment: The disks and mounted filesystems displayed using df -h serve as the storage attached to the KillerCoda VM.

3. Networking Resources
Purpose: Allows computers, storage, applications, and services to communicate with each other and connect to the internet.
Importance in cloud computing: Networking supports communication between services, security controls such as firewalls and VPCs, and access to applications from outside the system.
In this environment: The VM's IP address and hostname identify it within the network, similar to how cloud virtual machines use private or public IP addresses.

4. Operating System
Purpose: Controls hardware resources and provides the environment where applications and services can operate.
Importance in cloud computing: Most cloud servers run on operating systems, especially Linux, because it is lightweight, flexible, and open source.
In this environment: The Linux distribution and kernel version found in Checkpoint 2 represent the operating system layer running on the KillerCoda VM.
