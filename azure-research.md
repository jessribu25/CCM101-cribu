# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a major public cloud computing platform that was officially launched in 2010. It is widely used by organizations that already rely on Microsoft technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server.

## Global Infrastructure

* **Regions** – Geographic locations around the world that contain Azure data centers. Examples include East US, West Europe, Southeast Asia, Japan East, and Australia East.
* **Availability Zones** – Separate data centers within a region that have their own power, cooling systems, and network connections. They help improve reliability and availability.
* **Region Pairs** – A special Azure feature that connects two regions within the same geographic area to support disaster recovery and business continuity.

## Cloud Management Console

The **Azure Portal** is Microsoft's web-based platform for creating, managing, monitoring, and securing Azure resources. Users who need advanced control can also manage resources through Azure CLI or Azure PowerShell.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual servers that can be created when needed for running applications, websites, and databases.
2. **Azure Blob Storage** – A storage service designed for unstructured data, including documents, pictures, videos, and backup files.
3. **Azure Virtual Network (VNet)** – Creates secure private networks that allow virtual machines, cloud services, and on-premises systems to communicate with each other.
4. **Microsoft Entra ID** – Formerly known as Azure Active Directory, it provides cloud-based identity and access management, including features such as Single Sign-On (SSO) and Multi-Factor Authentication (MFA).

## Three Advantages

1. **Strong Microsoft integration** – Allows existing Microsoft technologies such as Windows Server, Active Directory, and Microsoft 365 to work together with cloud services.
2. **Effective hybrid cloud support** – Makes it possible to connect existing on-premises systems with cloud resources, allowing organizations to transition to the cloud gradually.
3. **Enterprise-level security and compliance** – Provides security features and compliance capabilities that make Azure suitable for organizations with strict regulatory requirements.

## Typical Enterprise Use Cases

* Businesses that already use Microsoft products and services
* Hybrid cloud environments combining local and cloud infrastructure
* Government, healthcare, and educational institutions
* Managing employee identities and access using Microsoft Entra ID
