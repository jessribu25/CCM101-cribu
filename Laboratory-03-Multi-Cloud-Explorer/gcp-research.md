# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a major public cloud computing service launched by Google in 2008. It uses the same worldwide infrastructure that supports services such as Google Search, YouTube, and Gmail. GCP is particularly recognized for its capabilities in artificial intelligence, machine learning, and large-scale data analytics. Google also developed Kubernetes, which has become a widely used platform for managing containers.

## Global Infrastructure

* **Regions** – Geographic locations containing Google Cloud data centers. Examples include us-central1 (Iowa), us-east1 (South Carolina), europe-west1 (Belgium), asia-southeast1 (Singapore), and asia-east1 (Taiwan).
* **Zones** – Separate locations within a region that provide redundancy and help improve service availability.
* **Google's Global Network** – Google operates a large private fiber-optic network that directly connects its data centers around the world, providing fast and reliable data transfer.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to create, configure, monitor, and manage GCP resources. It can also be used to deploy Kubernetes clusters. For automation and advanced management, users can utilize the `gcloud` command-line tool and Google Cloud APIs.

## Four Core Services

1. **Compute Engine** – Provides customizable virtual machines that allow users to run applications and workloads in the cloud.
2. **Cloud Storage** – An object storage service that offers different storage options depending on how frequently data needs to be accessed.
3. **Virtual Private Cloud (VPC)** – Provides isolated, software-based networks for securely connecting cloud resources.
4. **Cloud IAM** – Manages permissions and controls who can access specific cloud resources while following the Principle of Least Privilege.

## Three Advantages

1. **Strong AI, machine learning, and data analytics capabilities** – GCP provides powerful tools for developing AI solutions and processing large amounts of data.
2. **Kubernetes expertise** – Since Google originally developed Kubernetes based on its internal systems, GCP offers strong container management through services such as Google Kubernetes Engine (GKE).
3. **Fast private global network** – Google's privately owned fiber-optic infrastructure helps provide high-speed and dependable connections between its cloud data centers.

## Typical Enterprise Use Cases

* Developing artificial intelligence and machine learning applications
* Processing and analyzing large datasets
* Building cloud-native applications and microservices
* Running scalable applications and workloads using Kubernetes
