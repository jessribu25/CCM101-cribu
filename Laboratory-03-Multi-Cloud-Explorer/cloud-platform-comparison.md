## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** provides the widest selection of cloud services, with more than 200 offerings. Since it entered the cloud market in 2006, it has had more time to develop a large variety of specialized services for different business and technical needs.

### 2. Which provider has the best integration with Microsoft technologies?

**Microsoft Azure** is the strongest choice for Microsoft integration. It works closely with technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server, making it convenient for organizations already using Microsoft's products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is a strong choice for AI, machine learning, and Kubernetes. Google originally developed Kubernetes from its experience with its internal Borg system. GCP also provides powerful tools for artificial intelligence, data processing, and analytics.

### 4. Which cloud platform would you personally choose and why?

I would choose **AWS** for general-purpose projects because it has a wide range of services, strong documentation, and a mature cloud ecosystem. However, I would consider **GCP** for projects that focus heavily on artificial intelligence, machine learning, or data analytics.
