
# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is one of the world's leading public cloud computing platforms, introduced in 2006. It provides organizations with on-demand cloud resources such as computing power, storage, networking, databases, artificial intelligence, and machine learning. AWS serves a wide range of customers, including startups, large companies, and government organizations.

## Global Infrastructure

* **Regions** – Geographic areas around the world that contain multiple data centers. Examples include US East (N. Virginia), Europe (Frankfurt), Asia Pacific (Singapore), Asia Pacific (Tokyo), and Asia Pacific (Sydney).
* **Availability Zones (AZs)** – Separate data centers located within an AWS Region. They are designed to improve system reliability, availability, and protection against failures.
* **Edge Locations** – Locations used by Amazon CloudFront to store and deliver content closer to users, helping reduce network delays and improve loading speed.

## Cloud Management Console

The **AWS Management Console** is a web-based interface that allows users to manage AWS resources through a graphical environment. Users can create virtual machines, configure storage, set up networks, manage databases, monitor services, and check billing without directly using command-line tools. AWS also provides the AWS CLI and SDKs for users who prefer programmatic management.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers called EC2 instances that can run applications and adjust computing resources according to demand.
2. **Amazon S3** – A cloud-based object storage service used for storing files, backups, images, videos, and other types of data.
3. **Amazon RDS** – A managed relational database service that supports databases such as MySQL, PostgreSQL, and SQL Server while handling tasks like backups and maintenance.
4. **AWS IAM** – A security service used to control users, roles, and permissions while following the Principle of Least Privilege.

## Three Advantages

1. **Wide range of services** – AWS offers more than 200 cloud services that support different computing and business requirements.
2. **Scalability and elasticity** – AWS resources can be increased or decreased based on workload and demand.
3. **Established global ecosystem** – AWS has a large worldwide infrastructure, extensive documentation, and a well-developed cloud computing ecosystem.

## Typical Enterprise Use Cases

* Hosting websites and developing applications
* Performing data analytics and machine learning
* Creating disaster recovery solutions
* Supporting enterprise systems in industries such as finance, healthcare, education, and government
