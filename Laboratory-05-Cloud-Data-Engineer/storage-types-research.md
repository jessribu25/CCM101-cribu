# Cloud Storage Types Research

| Storage Type       | Description                                                                                                                                                                   | Primary Use Case                                                                                   | Cloud Provider Example                                 |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **Block Storage**  | Stores information in separate blocks and provides them to a virtual machine as a storage volume. The operating system is responsible for formatting and organizing the data. | Commonly used for operating systems, boot drives, and databases that need fast data processing.    | Amazon EBS, Azure Disk Storage, Google Persistent Disk |
| **File Storage**   | Saves data as files and organizes them into folders. These files can be accessed through a network using protocols such as NFS or SMB.                                        | Useful for shared folders where multiple users or virtual machines need to access the same files.  | Amazon EFS, Azure Files, Google Cloud Filestore        |
| **Object Storage** | Keeps data as individual objects inside storage containers or buckets. Each object contains the data, additional information called metadata, and a unique identifier.        | Mainly used for storing large amounts of files such as photos, videos, backups, and archived data. | Amazon S3, Azure Blob Storage, Google Cloud Storage    |

## Why Object Storage Is Best for the Client's Photos

For a photo-sharing application that may receive millions of uploaded pictures, **Object Storage** is the most appropriate option. It can handle huge amounts of unstructured data and can easily expand as more photos are added. Unlike block storage, which is mainly designed for high-performance applications and databases, object storage is better suited for files such as images and videos. It can also be accessed through HTTP/HTTPS, making it easier to connect with a web application. Another advantage is that it is usually more affordable for storing large numbers of photos that are not frequently modified.
