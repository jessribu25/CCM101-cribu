# Laboratory Activity 5: Mission 5 – The Cloud Data Engineer

## Mission Overview

In this activity, I learned about the differences between Block, File, and Object Storage. I also set up my own S3-compatible object storage server using MinIO and Docker. I created a storage bucket and uploaded a file to verify that the setup was working properly. This activity gave me practical experience with a task similar to what a cloud data engineer might perform.

## Objectives

* Understand the differences between Block, File, and Object Storage
* Set up an S3-compatible Object Storage server using MinIO and Docker
* Access a cloud service through a web interface using port forwarding
* Create storage buckets and upload files as objects
* Record and explain cloud storage procedures using Markdown
* Add more practical cloud computing experience to my GitHub portfolio

## Tools Used

* **KillerCoda Playground** – Ubuntu and Docker environment
* **Docker** – Used to run the MinIO container
* **MinIO** – S3-compatible object storage service
* **GitHub** – Used for documenting and maintaining my cloud computing portfolio

## Skills Learned

* Understanding the differences between different cloud storage architectures and their uses
* Deploying a containerized service with Docker and environment variables
* Connecting to a cloud service through port forwarding
* Creating storage buckets and uploading files using a web console
* Properly documenting technical procedures and deployments using Markdown
