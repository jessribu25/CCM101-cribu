# Docker Deployment Log

| Command                | Description                                                |
| ---------------------- | ---------------------------------------------------------- |
| `docker ps`            | Checks the running containers.                             |
| `docker stop my-nginx` | Stops the `my-nginx` container.                            |
| `docker ps -a`         | Checks all containers and confirms `my-nginx` has stopped. |
| `docker rm my-nginx`   | Removes the stopped `my-nginx` container.                  |
